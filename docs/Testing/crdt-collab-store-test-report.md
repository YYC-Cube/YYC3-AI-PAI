## ⚠️ 已知限制

1. **Yjs Mock限制**: 由于Yjs的复杂性，某些文档操作可能无法完全模拟
2. **Immer冻结问题**: 某些操作可能会遇到Immer冻结的对象，需要进一步优化
3. **WebSocket/WebRTC Mock**: 这些网络连接的Mock是简化的，实际行为可能不同
