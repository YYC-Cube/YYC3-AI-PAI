**3个测试失败**，全部由Immer冻结对象导致（store实现问题）：

1. **duplicate workflow** - `workflows.size`在操作后没有正确更新
2. **cancel workflow** - store内部尝试修改冻结的status属性
3. **self-heal timeout error** - store内部尝试修改冻结的selfHealingCount属性

**注意**: 这些失败是由store内部实现的问题，不是测试代码的问题。store中的某些方法直接修改了被Immer冻结的对象，需要修复store实现。
