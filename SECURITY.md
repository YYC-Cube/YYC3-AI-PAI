# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 4.x     | ✅ Active development |

## Reporting a Vulnerability

We take the security of YYC³ AI-PAI seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do NOT report security vulnerabilities through public GitHub issues.**

Instead, please report them via email to **admin@0379.email**.

You should receive a response within 48 hours. If for some reason you do not, please follow up via email to ensure we received your original message.

Please include the following information:
- Type of issue (e.g. XSS, CSRF, SQL injection, etc.)
- Full paths of source file(s) related to the manifestation of the issue
- The location of the affected source code (tag/branch/commit or direct URL)
- Any special configuration required to reproduce the issue
- Step-by-step instructions to reproduce the issue
- Proof-of-concept or exploit code (if possible)
- Impact of the issue, including how an attacker might exploit it

## Preferred Languages

We prefer all communications to be in English or Chinese.

## Policy

We follow responsible disclosure principles:
1. Report the vulnerability privately
2. We will acknowledge receipt within 48 hours
3. We will investigate and provide a timeline for fix
4. We will release a fix and coordinate disclosure

## Scope

- Core application code in `/src`
- Build and deployment configurations
- API endpoints and data handling

The following are considered out of scope:
- Third-party dependencies (please report to respective maintainers)
- Issues related to outdated browsers
- Social engineering attacks

## Recognition

We maintain a list of security researchers who have responsibly disclosed vulnerabilities. If you would like to be credited, please include your preferred name/alias in your report.
